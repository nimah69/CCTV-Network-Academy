# راهنمای روش‌های یادگیری

## مفاهیم کلیدی
- هدف: ساختن نقشه ذهنی فصل و جداکردن مفهوم‌های اصلی از جزئیات.
- قالب: کارت‌های مستقل؛ هر کارت یک تعریف یا ایده را توضیح می‌دهد.
- رفتار: کاربر کارت‌ها را با ترتیب دلخواه مرور می‌کند و برای فهم پایه‌ای از آن‌ها استفاده می‌کند.
- معیار کیفیت: کارت‌ها نباید صرفاً همان پرسش‌ها و بازخوردهای آزمون را تکرار کنند.

## بازیابی فعال
- هدف: کمک به یادگیرنده برای به‌یادآوردن مفهوم بدون دیدن پاسخ از ابتدا.
- قالب: پرسش مرحله‌ای، انتخاب پاسخ، سپس بازخورد و دلیل پاسخ صحیح.
- رفتار: پاسخ درست و نادرست باید هر دو توضیح داشته باشند؛ پرسش‌ها از بانک سؤال فصل انتخاب شوند.
- معیار کیفیت: متن کارت‌های مفاهیم کلیدی نباید عیناً در بخش بازیابی فعال کپی شود.

## ادامه یادگیری
«ادامه یادگیری» صفحه مدیریت پیشرفت، موقعیت آخر مطالعه، سؤال‌های نیازمند مرور و نتیجه آزمون است؛ با «بازیابی فعال» که یک روش تمرین درون درس است تفاوت دارد.
