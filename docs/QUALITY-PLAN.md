# برنامه کنترل کیفیت و توسعه آکادمی

## وضعیت مورد اتکا
- مالک پروژه تأیید کرده است که قابلیت‌های فعلی در مرورگر موبایل آزمایش شده و موفق بوده‌اند.
- آزمون موبایل، بررسی علمی محتوا و آزمون خودکار کد سه نوع تأیید جدا هستند؛ یکی جای دیگری را نمی‌گیرد.
- پیشرفت کاربر در حال حاضر در localStorage همان مرورگر ذخیره می‌شود.

## دروازه‌های انتشار
1. اجرای `node tests/quality-check.mjs` برای بررسی syntax و ساختار بانک سؤال.
2. اجرای موفق workflow کیفیت در GitHub Actions.
3. اجرای موفق workflow انتشار Pages که به نتیجه مرحله کیفیت وابسته است.
4. بعد از تغییرات رابط کاربری یا ابزارها، تأیید دستی مالک روی گوشی.
5. برای ادعاهای حساس فنی و استانداردها، بازبینی منبع معتبر و ثبت نسخه/دامنه آن.

## پوشش آزمون خودکار
- تعداد ۱۴ فصل و ۲۵ سؤال در هر فصل.
- چهار گزینه یکتا، اندیس پاسخ معتبر و توضیح کافی برای هر سؤال.
- برچسب نوع پرسش برای تفکیک بازنویسی سؤال منبع، پرسش تمرینی، سناریو و تمرین مفهومی تکمیلی.
- تنوع صورت سؤال و توزیع پاسخ صحیح میان گزینه‌ها.
- بررسی ساختاری JavaScript و آزمون‌های مرزی منتخب محاسبه‌گرها.

## نمونه‌های مرجع برای محاسبه‌گرها
این مقادیر برای کنترل فرمول هستند، نه جایگزین مشخصات سازنده یا طراحی مهندسی نهایی:
- PoE: هشت دوربین با مصرف ۱۲ وات و ذخیره ۲۵٪، بار تخمینی ۱۲۰ وات.
- پهنای باند: شانزده جریان ۴ Mbps با حاشیه ۳۰٪، برآورد ۸۳٫۲ Mbps.
- ذخیره‌سازی: هشت جریان ۴ Mbps برای ۱۴ روز ضبط پیوسته، حدود ۴٫۸۴ TB ده‌دهی پیش از حاشیه؛ با ۱۰٪ حاشیه حدود ۵٫۳۲ TB.
- در محاسبات واقعی باید Bitrate اندازه‌گیری‌شده، ساعات ضبط، سربار، RAID و ظرفیت قابل استفاده لحاظ شود.

## برنامه معماری مرحله‌ای
1. ابتدا داده آموزشی و بانک سؤال از منطق رابط کاربری جدا شوند، بدون تغییر رفتار و ظاهر فعلی.
2. سپس منطق محاسبه‌گرها و آزمون‌ها به ماژول‌های مستقل منتقل شود و برای هر ماژول آزمون اضافه شود.
3. پس از هر گام، آزمون خودکار و آزمون دستی موبایل اجرا شود؛ اگر هر کدام شکست خورد، همان گام متوقف یا بازگردانی شود.
4. فقط بعد از تثبیت این مراحل، نصب‌پذیری PWA و قابلیت‌های جدید بررسی شوند.

## تطبیق با PDF
- فقط برای صفحه‌هایی که با نسخه اصلی PDF بررسی شده‌اند ارجاع دقیق درج شود.
- سؤال‌های بازنویسی‌شده از جزوه از تمرین‌های طراحی‌شده برای آموزش جدا بمانند.
- اگر نسخه PDF در دسترس نباشد، هیچ شماره صفحه یا نقل‌قولی حدس زده نشود.
