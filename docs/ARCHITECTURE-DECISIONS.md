# تصمیم معماری: جست‌وجو و ساختار صفحه

## جست‌وجوی ریزدرس
جست‌وجو در عنوان فصل‌ها، بخش‌های فعلی و متن ریزدرس‌ها انجام می‌شود؛ شامل تعریف، توضیح تکمیلی، مثال، اشتباه رایج، ارتباط با سامانه و نکته عملی. نتیجه ریزدرس مستقیم به همان گام هدایت می‌کند.

## چرا CSS و JavaScript درون index.html فعلاً جدا نشدند؟
بخش اصلی برنامه هنوز از تابع‌های سراسری و handlerهای inline در قالب‌های درس، آزمون و آزمایشگاه استفاده می‌کند. انتقال یک‌باره به فایل‌های جدا، دامنه تابع‌ها، ترتیب بارگذاری، مسیرهای file:// و precache را هم‌زمان تغییر می‌دهد. تا وقتی آزمون رفتاری مرورگر و WebView برای این مرزها وجود ندارد، این بازآرایی ریسک بیشتری از فایده فوری دارد؛ بنابراین به‌تعویق افتاد. فایل‌های داده و ماژول‌های مستقل که از قبل جدا شده‌اند، همچنان جدا باقی می‌مانند.

## آزمون دستی باقی‌مانده
CI نحو و ساختار و APK را بررسی می‌کند؛ پیمایش با Back، حالت پرواز، اندازه ۳۶۰ پیکسل و خوانایی فونت باید روی گوشی واقعی طبق چک‌لیست ثبت شود.
