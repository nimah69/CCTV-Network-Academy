# آکادمی شبکه و نظارت تصویری (CCTV-Network-Academy)

یک وب‌اپلیکیشن آموزشی فارسی و راست‌چین برای یادگیری مبانی شبکه، سامانه‌های CCTV، امنیت فیزیکی، امنیت سایبری و عیب‌یابی.

## وضعیت نسخه فعلی
- نسخه اولیه قابل استفاده (MVP) در یک فایل مستقل `index.html` ساخته شده است.
- ۱۴ فصل آموزشی با محتوای خلاصه‌شده بر پایه جزوه «جزوه جامع آمادگی آزمون و مصاحبه افتا — پیاده‌سازی امنیت فیزیکی و محیط پیرامونی / نظارت تصویری».
- آزمون‌های فصل‌به‌فصل، آزمون جامع، بازخورد پاسخ‌ها و توضیح پاسخ صحیح.
- جست‌وجوی فصل‌ها و مفاهیم.
- ذخیره پیشرفت در حافظه محلی مرورگر همان دستگاه.
- طراحی واکنش‌گرا برای گوشی و رایانه، بدون وابستگی به کتابخانه یا سرویس پولی خارجی.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای استفاده آنلاین می‌توان GitHub Pages را پس از بررسی تنظیمات و سطح دسترسی مخزن فعال کرد.

## منبع و دقت محتوا
محتوا خلاصه و سازمان‌دهی آموزشی از PDF ارائه‌شده توسط مالک پروژه است؛ متن PDF به‌صورت کامل در مخزن کپی نشده است. عنوان‌ها یا جزئیات ناقص در منبع با حدس پر نشده‌اند. پرسش‌های آزمون در فصل «سؤالات چهارگزینه‌ای جزوه» بر پایه پرسش‌های درج‌شده در PDF تنظیم شده‌اند؛ آزمون‌های فصل‌های دیگر پرسش‌های تمرینی تدوین‌شده بر اساس محتوای همان جزوه‌اند.

این نسخه هنوز آزمون نهایی روی دستگاه‌های مختلف و انتشار عمومی را پشت سر نگذاشته است. پیشرفت کاربر فقط در حافظه محلی مرورگر ذخیره می‌شود و بین دستگاه‌ها همگام نیست.

## قدم‌های بعدی
1. آزمون عملی روی گوشی و بررسی تمام مسیرهای درس/آزمون.
2. گسترش سؤال‌ها و افزودن مرور دقیق‌تر صفحات منبع.
3. افزودن امکان نصب‌پذیری (PWA) و دسترس‌پذیری بهتر.
4. فعال‌سازی انتشار آنلاین پس از تصمیم درباره عمومی یا خصوصی ماندن مخزن.
